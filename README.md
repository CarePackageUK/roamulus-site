# roamulus.com (launch pages)

Static site for roamulus.com: the homepage, the privacy
policy (`/privacy/`) and support (`/support/`). Served by GitHub Pages with the custom domain in `CNAME`.
App screenshots in `assets/app/` are real dark-mode captures from the iOS simulator. When Roamulus is on the App Store,
swap the "Coming soon" buttons in `index.html` for the App Store link.
